# CI/CD

## Core concepts
Continuous integration, delivery vs deployment, pipeline stages, artifacts, runners, approvals, secrets, caching, quality gates, rollback and deployment strategies.

## Commands and tools
Jenkinsfile, GitHub Actions YAML, artifact versioning, pipeline logs.

## Interview questions
Secure pipeline secrets? Promote same artifact? Implement rollback? Debug flaky pipeline? What is a canary?

## Hands-on lab
Build, test, scan and publish a container image; deploy an immutable image tag.

## Answer framework
Use **Context → Explanation → Example → Trade-off → Validation**. For scenarios use **Impact → Evidence → Hypothesis → Test → Mitigation → Prevention**.
