# AWS

## Core concepts
IAM, STS, EC2, Auto Scaling, ALB/NLB, VPC, subnets, route tables, NAT, security groups, NACLs, S3, ECR, EKS, CloudWatch, KMS and Secrets Manager.

## Commands and tools
AWS CLI: `sts get-caller-identity`, `ec2 describe-instances`, `eks describe-cluster`, `ecr get-login-password`.

## Interview questions
Security group vs NACL? Public vs private subnet? How does EKS pull from ECR? Design private EKS nodes. Debug unreachable EC2.

## Hands-on lab
Draw a VPC with public/private subnets. Use a sandbox account, budgets and cleanup. Check current pricing.

## Answer framework
Use **Context → Explanation → Example → Trade-off → Validation**. For scenarios use **Impact → Evidence → Hypothesis → Test → Mitigation → Prevention**.
