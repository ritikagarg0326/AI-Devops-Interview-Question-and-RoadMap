# Linux

## Core concepts
Filesystem, users/groups, permissions, processes, signals, systemd, packages, environment variables, logs and storage.

## Commands and tools
`pwd`, `ls -la`, `find`, `grep`, `awk`, `sed`, `chmod`, `chown`, `ps`, `top`, `free`, `df`, `du`, `ss`, `lsof`, `journalctl`, `systemctl`, `tar`, `curl`, `ssh`, `scp`.

## Interview questions
What happens during boot? Process vs thread? Find the process using a port. Diagnose high CPU, memory or disk. Hard link vs soft link? How do you inspect service logs?

## Hands-on lab
Create a non-root user, configure SSH keys in a disposable VM, create a systemd service and diagnose a deliberately broken service.

## Answer framework
Use **Context → Explanation → Example → Trade-off → Validation**. For scenarios use **Impact → Evidence → Hypothesis → Test → Mitigation → Prevention**.
