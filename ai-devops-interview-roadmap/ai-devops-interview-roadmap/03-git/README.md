# Git and GitHub

## Core concepts
Working tree, staging, commits, branches, merge, rebase, tags, remotes, pull requests, code review and versioning.

## Commands and tools
`git status`, `git log --oneline --graph`, `git diff`, `git switch`, `git restore`, `git reset`, `git revert`, `git cherry-pick`, `git rebase`, `git stash`, `git bisect`.

## Interview questions
Merge vs rebase? Reset vs revert? Recover a deleted commit? Resolve conflicts? What is a protected branch?

## Hands-on lab
Create a feature branch, introduce and resolve a conflict, rebase and revert a shared commit.

## Answer framework
Use **Context → Explanation → Example → Trade-off → Validation**. For scenarios use **Impact → Evidence → Hypothesis → Test → Mitigation → Prevention**.
