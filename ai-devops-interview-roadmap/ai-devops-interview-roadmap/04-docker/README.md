# Docker

## Core concepts
Images, layers, containers, registries, namespaces, cgroups, volumes, bind mounts, networks, health checks and multi-stage builds.

## Commands and tools
`docker build`, `run`, `ps`, `logs`, `exec`, `inspect`, `stats`, `network`, `volume`, `compose`.

## Interview questions
Image vs container? COPY vs ADD? ENTRYPOINT vs CMD? How do layers affect caching? Reduce image size? Container communication?

## Hands-on lab
Containerize an API with a non-root user, health check, multi-stage build and Compose database.

## Answer framework
Use **Context → Explanation → Example → Trade-off → Validation**. For scenarios use **Impact → Evidence → Hypothesis → Test → Mitigation → Prevention**.
