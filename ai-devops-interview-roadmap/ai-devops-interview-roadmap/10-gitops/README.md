# GitOps, Helm and Argo CD

## Core concepts
Desired state, reconciliation, declarative config, Helm charts, values, templates, releases, Argo CD apps, sync, drift and rollback.

## Commands and tools
`helm lint`, `helm template`, `helm upgrade --install`, `kubectl get applications`.

## Interview questions
What is GitOps? How does Argo CD detect drift? Helm install vs upgrade? Manage secrets? What if sync fails?

## Hands-on lab
Package a sample app with Helm and deploy it through Argo CD from Git.

## Answer framework
Use **Context → Explanation → Example → Trade-off → Validation**. For scenarios use **Impact → Evidence → Hypothesis → Test → Mitigation → Prevention**.
