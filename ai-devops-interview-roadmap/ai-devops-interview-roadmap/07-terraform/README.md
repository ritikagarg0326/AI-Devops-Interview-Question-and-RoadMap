# Terraform

## Core concepts
Providers, resources, data sources, variables, outputs, locals, modules, state, plan/apply, import, lifecycle, workspaces, remote backend and locking.

## Commands and tools
`terraform fmt`, `validate`, `init`, `plan`, `apply`, `state list`, `import`, `output`.

## Interview questions
Why state? What if state is lost? How do you handle drift? Why remote state and locking? count vs for_each?

## Hands-on lab
Create a reusable network module in a sandbox and practise remote state and resource import.

## Answer framework
Use **Context → Explanation → Example → Trade-off → Validation**. For scenarios use **Impact → Evidence → Hypothesis → Test → Mitigation → Prevention**.
