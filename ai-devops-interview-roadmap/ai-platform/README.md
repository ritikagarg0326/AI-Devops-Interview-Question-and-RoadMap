# AI interview platform starter

MVP: choose target role/experience/topic, start an interview, receive one question, submit answer, receive structured feedback and track weak areas.

The current backend demonstrates API contracts and mock responses. It does not yet persist user data or call a real model.

Next: add PostgreSQL/SQLAlchemy, auth, retrieval over reviewed Markdown, provider adapter, rate limits, telemetry, cost controls and React screens. Keep model keys on the backend only.
