# React frontend blueprint

Build with React + TypeScript.

Screens:
- Dashboard: streak, confidence by topic and recent sessions.
- Roadmap: milestones and completion status.
- Practice setup: role, experience, topic, difficulty and question type.
- Interview room: one question at a time, answer editor and submit.
- Feedback: score, evidence, strengths, gaps, improved answer and follow-up.
- Progress: topic trends and recommended practice.

Suggested folders: `components/`, `pages/`, `services/api.ts`, `types/`. Include loading, error and empty states. Never put model API keys in browser code.
