# Networking

## Core concepts
OSI/TCP-IP, subnetting, DNS, DHCP, ARP, routing, NAT, TCP handshake, UDP, HTTP, TLS, proxies and load balancers.

## Commands and tools
`ip addr`, `ip route`, `ss -tulpn`, `dig`, `nslookup`, `curl -v`, `traceroute`, `ping`, `nc`, `openssl s_client`.

## Interview questions
What happens when you enter a URL? How does DNS work? TCP vs UDP? What is TLS termination? Debug intermittent timeouts.

## Hands-on lab
Trace DNS resolution, inspect a TLS certificate and use curl to inspect response headers.

## Answer framework
Use **Context → Explanation → Example → Trade-off → Validation**. For scenarios use **Impact → Evidence → Hypothesis → Test → Mitigation → Prevention**.
