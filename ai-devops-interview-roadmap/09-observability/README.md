# Observability

## Core concepts
Metrics, logs, traces, RED/USE, Prometheus scrape model, exporters, PromQL, Grafana, alert routing, SLI/SLO/SLA and alert fatigue.

## Commands and tools
`up`, `rate()`, `sum()`, `histogram_quantile()` and Grafana dashboards.

## Interview questions
Prometheus vs Grafana? High-cardinality label? Alert on error rate? What makes an actionable alert?

## Hands-on lab
Instrument a demo service, collect metrics, build a dashboard and alert on elevated errors.

## Answer framework
Use **Context → Explanation → Example → Trade-off → Validation**. For scenarios use **Impact → Evidence → Hypothesis → Test → Mitigation → Prevention**.
