# Mock interview framework

- **Round 1 – Fundamentals:** Linux, networking, Git and Docker.
- **Round 2 – Platform:** Kubernetes, AWS, Terraform and CI/CD.
- **Round 3 – Operations:** incidents, debugging, reliability and communication.
- **Round 4 – Design:** design a secure, observable deployment platform.

Score each 1–5: concept accuracy 25%, troubleshooting 25%, practical experience 20%, security/reliability 15%, communication 15%.
