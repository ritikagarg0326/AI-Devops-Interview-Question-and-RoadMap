# 30-day focused plan

Spend 90–120 minutes daily: theory, lab, interview practice and notes.

| Day | Focus | Deliverable |
|---:|---|---|
| 1 | Linux files, users, permissions | command cheat sheet |
| 2 | Processes, systemd, logs | diagnose failed service |
| 3 | Bash | log parsing script |
| 4 | DNS, TCP/IP, ports | request-flow diagram |
| 5 | HTTP, TLS, load balancing | explain TLS termination |
| 6 | Git basics | branching exercise |
| 7 | Git advanced | conflict, rebase, revert |
| 8 | Docker basics | containerize an app |
| 9 | Dockerfile optimization | multi-stage build |
| 10 | Compose, volumes, networks | multi-container app |
| 11 | Kubernetes architecture | draw control plane |
| 12 | Pods, Deployments | deploy an app |
| 13 | Services, Ingress | expose the app |
| 14 | Probes, resources, scheduling | debug failing Pod |
| 15 | ConfigMaps, Secrets, storage | mount configuration |
| 16 | Kubernetes security | RBAC exercise |
| 17 | AWS IAM, EC2, S3 | least-privilege notes |
| 18 | VPC, subnets, routes | VPC diagram |
| 19 | ECR, EKS, load balancers | deployment flow |
| 20 | Terraform basics | provision sandbox resource |
| 21 | Terraform state and modules | reusable module |
| 22 | Jenkins | build-test-push pipeline |
| 23 | GitHub Actions | CI workflow |
| 24 | Helm | package Kubernetes app |
| 25 | Argo CD | GitOps sync demo |
| 26 | Prometheus, Grafana | dashboard and alert |
| 27 | DevSecOps | scan image and dependencies |
| 28 | Incidents | three runbooks |
| 29 | System design | reliable deployment platform |
| 30 | Mock interview | score and review gaps |

Do not mark a day complete until its deliverable works and you can explain it without notes.
