# 60-day roadmap

- Days 1–10: Linux, shell scripting, networking and Git.
- Days 11–20: Docker, image security, Compose and container troubleshooting.
- Days 21–32: Kubernetes architecture, workloads, networking, storage, security and troubleshooting.
- Days 33–40: AWS IAM, VPC, EC2, S3, ECR, EKS, load balancing and CloudWatch.
- Days 41–47: Terraform, state, modules, remote backend and drift.
- Days 48–53: Jenkins, GitHub Actions, Helm and Argo CD.
- Days 54–56: Prometheus, Grafana, logging, alerting and SLOs.
- Days 57–58: DevSecOps, reliability, backup, disaster recovery and cost.
- Days 59–60: Two mock interviews and a focused revision plan.

Publish one lab each week with a diagram, commands, expected output and troubleshooting notes.
