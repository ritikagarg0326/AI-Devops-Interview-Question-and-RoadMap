# Python and Bash for DevOps

## Core concepts
Arguments, exit codes, exceptions, subprocess, files, JSON/YAML, HTTP APIs, logging, retries, idempotency and safe shell practices.

## Commands and tools
Python `argparse`, `subprocess.run`, `logging`; Bash `set -euo pipefail`, traps and exit codes.

## Interview questions
Handle subprocess failures? Why avoid shell=True with untrusted input? Make scripts idempotent? Add retries?

## Hands-on lab
Write a health-check script that parses logs and returns meaningful exit codes.

## Answer framework
Use **Context → Explanation → Example → Trade-off → Validation**. For scenarios use **Impact → Evidence → Hypothesis → Test → Mitigation → Prevention**.
